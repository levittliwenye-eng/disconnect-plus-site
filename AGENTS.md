# DISCONNECT+ Website Notes

- Keep the visual language black, stark, surreal, noisy, and archival.
- Preserve the real audio and image assets under `public/audio` and `public/images`.
- Public pages should work with local demo data when Cloudflare D1 is not configured.
- Production content and order intake should use Cloudflare Pages Functions with the schema in `cloudflare/d1/schema.sql`.
- Avoid marketing-style hero cards; the band name and imagery should carry the first viewport.
